To create or load a campaign from the cloud, use the menu. A campaign is a collection of characters, which you can share with other users to collaborate.
To load a character from the cloud, select their name from the menu; you can also load an older version if you realize you made a mistake. To load a character from a file, drag and drop the .json file from your computer onto the browser window.
To save a character, click to upload it to the cloud, or to download it to a local JSON file. The file is named after the character name, and character sheets with the same name in the same campaign will overwrite one another; if you change the name it will save to a different file. You can also press Ctrl+S / ⌘S to save.
