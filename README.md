# Cortex Character Sheet

*Originally forked from [tamas-rabel.github.io](https://github.com/tamas-rabel/tamas-rabel.github.io)*

A [character sheet](./cortex/sheet.html) for the [Cortex Prime RPG](https://www.cortexrpg.com/) (or other *Cortex* variations) supporting open-ended content blocks across two columns and multiple pages, and saving and restoring characters via local JSON files and via a Firebase cloud instance.
